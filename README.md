# HydroPredict — The Aqua-Epoch (techFEST'26)

HydroPredict is an end-to-end Machine Learning pipeline and REST API dashboard built for **The Aqua-Epoch** at **techFEST'26 (SLIET, Longowal)**.

## Project Structure
- `train_model.py`: Training script for XGBoost Classifier & LightGBM Regressor.
- `api.py`: Asynchronous FastAPI REST service backend.
- `app.py`: Streamlit dashboard web interface.
